# Cafe Kinship: The Game

## Get it

**The easy way:** install the [Cafe Kinship app for Windows](https://www.cafekinship.com/download),
open **Games** in its sidebar and press **Install**. The app keeps the game up
to date, and updates only download what changed.

**Or by hand:** download the latest version from **Releases** (right side of
this page): it's the `CafeKinship-Windows` zip under **Assets**.
1. Unzip it somewhere (right-click → Extract All).
2. Open the folder and double-click the game's .exe in the main folder.
3. If Windows says "Windows protected your PC", click **More info → Run anyway**.
   That shows up for any game that isn't from a store; it's not a virus warning.

The release called **Game files for the Cafe Kinship app** is what the app
downloads from. You don't need anything from it.

## You'll need
- Windows 10 or 11 (64-bit)
- A graphics card that supports DirectX 12
- About 3 GB of free space
