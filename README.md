# Cafe Kinship: The Game

Download the latest version from **Releases** (right side of this page): it's the
`CafeKinship-Windows` zip under **Assets**.

## How to play
1. Download the zip and unzip it somewhere (right-click → Extract All).
2. Open the folder and double-click the game's .exe in the main folder.
3. If Windows says "Windows protected your PC", click **More info → Run anyway**.
   That shows up for any game that isn't from a store; it's not a virus warning.

## You'll need
- Windows 10 or 11 (64-bit)
- A graphics card that supports DirectX 12
- About 3 GB of free space
